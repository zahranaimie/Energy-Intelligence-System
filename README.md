

\# ⚡ Energy Intelligence System



An interactive Energy Intelligence platform for household electricity consumption analysis, machine learning forecasting, anomaly detection, cost estimation, and sustainability analytics.



\## Project Overview



This project analyzes household electricity consumption data and transforms it into useful insights through data analytics, machine learning, and interactive visualization.



\## Main Features



1\. Executive Overview

2\. Consumption Analytics

3\. Advanced Energy Analysis

4\. Peak Demand Monitoring

5\. AI Forecasting Studio

6\. Model Comparison Lab

7\. Anomaly Detection Center

8\. Energy Cost Calculator

9\. Carbon Emission Monitor

10\. What-if Simulator

11\. Automated Insights \& Reports

12\. Data Management \& Explorer



\## Machine Learning Models



\- Linear Regression

\- Random Forest Regressor

\- Hist Gradient Boosting Regressor

\- Isolation Forest for anomaly detection



\## Dataset



Individual Household Electric Power Consumption Dataset.



Source: Kaggle Machine Learning Repository



https://www.kaggle.com/datasets/uciml/electric-power-consumption-data-set


The dataset contains household electricity measurements collected over several years.

\## Installation



Clone the repository:



```bash

git clone YOUR\_REPOSITORY\_URL

cd Energy\_Intelligence\_System

```



Install dependencies:



```bash

pip install -r requirements.txt

```



\## Run the Application



```bash

streamlit run app/app.py

```

Forecasts, electricity costs, and carbon emissions are estimates. Their accuracy depends on data quality, model performance, and user-provided assumptions.
